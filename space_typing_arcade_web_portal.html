HƯỚNG DẪN ĐƯA WEB LÊN ONLINE

Làm Thế Nào Để Đưa Trang Web Này Lên Mạng (Miễn Phí 100%)?

Bạn không cần mua Hosting hay Tên miền! Chỉ với 1 file index.html này, bạn có thể đưa game lên internet công khai cho bạn bè hoặc học sinh cùng chơi.

01

Cách 1: Kéo - Thả vào Netlify Drop (Nhanh nhất - 30 giây)

Không cần đăng ký tài khoản rườm rà!

  1. Lưu file mã nguồn này thành tên index.html trên máy tính.
  2. Tạo 1 thư mục mới (ví dụ my-typing-game) và bỏ file index.html vào đó.
  3. Truy cập trang web miễn phí: app.netlify.com/drop
  4. Kéo nguyên thư mục đó thả vào ô trên trang Netlify.
  5. Xong! Bạn sẽ nhận ngay 1 đường link trang web public dạng https://xxxx.netlify.app!
02

Cách 2: Đăng qua GitHub Pages (Bền vững lâu dài)

Dành cho bạn nào đã có tài khoản GitHub

  1. Đăng nhập GitHub.com và tạo một Repository mới (ví dụ: space-typing).
  2. Upload file index.html vào Repository đó.
  3. Vào mục **Settings** -> chọn tab **Pages** ở menu bên trái.
  4. Tại phần **Branch**, chọn main (hoặc master) và nhấn **Save**.
  5. Chờ khoảng 1 phút, GitHub sẽ cấp link dạng https://username.github.io/space-typing.
